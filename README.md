# 🤖 AI Multi-PDF & Word Chatbot using Retrieval-Augmented Generation (RAG)

An AI-powered document intelligence platform that enables users to upload multiple PDF and Word documents, ask questions in natural language, generate AI images, and create instant quizzes from uploaded content. The application leverages Retrieval-Augmented Generation (RAG) to retrieve relevant information from documents and generate accurate, context-aware responses using Google's Gemini models.

---

# 🚀 Features

## 📂 Multi-Document Upload

* Upload multiple PDF documents.
* Upload Microsoft Word (.docx) documents.
* Process multiple documents into a single searchable knowledge base.

## 💬 AI Document Chat

* Ask questions in natural language.
* Answers generated strictly from uploaded documents.
* Context-aware responses using Retrieval-Augmented Generation (RAG).
* Maintains conversation history.
* Fast semantic document retrieval.

## 📖 Source Citation & Page References

* Displays the source document name for every response.
* Shows the exact page number(s) where the answer was found.
* Enables users to verify AI-generated responses directly from the original document.

## 📚 Intelligent Document Processing

* Automatic text extraction.
* Smart text chunking.
* Embedding generation.
* Semantic similarity search.
* FAISS Vector Database for efficient retrieval.

## 📝 Instant AI Quiz Generator

Generate quizzes directly from uploaded documents.

### Quiz Features

* Easy, Medium, and Hard difficulty levels
* Multiple Choice Questions (MCQs)
* Instant score calculation
* Correct answers
* Detailed explanations for every question
* Performance summary after quiz completion

## 🎨 AI Image Generation

* Generate AI images from text prompts.
* Download generated images.
* Integrated image generation within the application.

## 🎯 Modern User Interface

* ChatGPT-inspired interface.
* Responsive Streamlit application.
* Sidebar document management.
* Clean and user-friendly experience.

# ⚙️ System Workflow

1. Upload one or more PDF or Word documents.
2. Extract text from documents.
3. Split text into semantic chunks.
4. Generate vector embeddings.
5. Store embeddings in the FAISS vector database.
6. Ask questions in natural language.
7. Retrieve the most relevant document chunks.
8. Generate answers using Gemini based only on retrieved content.
9. Display the source document name and page number(s).
10. Generate quizzes or AI images on demand.
